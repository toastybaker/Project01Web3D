## Negative references

- `references/negative/owner-frames/`: four screenshots explicitly identified by the owner as unacceptable.
- `references/negative/unity-captures/`: 72 additional Unity implementation captures retained to prevent regression.

Recurring failures represented in the negative set:

- Over-scaled fences, booths, portals, and UI.
- Flat or desolate terrain and missing grass hierarchy.
- White glow/material clipping.
- Asset-family mismatch and disconnected prop placement.
- UI overlap, weak typography, excessive text, and poor responsive anchoring.
- Inventory and shops that look copied, repetitive, or spreadsheet-like.
- World layouts that read as prototypes rather than believable destinations.
- Features considered complete because transactions succeeded despite weak presentation.

# C# Behavior Reference

These files preserve tested rules and edge cases for farming, inventory, shops, stocks, rounds, interactions, and player state. They are reference material for the authoritative TypeScript/Colyseus rewrite.

Do not compile them into the web project. Do not port their Unity presentation, GameObject assumptions, RPC structure, HUD calls, or scene dependencies. Extract behavior into framework-independent shared data and server commands, then cover it with TypeScript tests.
